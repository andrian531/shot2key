# Shot2Key

GUI Studio & Storyboard Keyframe Generator powered by [`JuneYaooo/rea-video`](https://github.com/JuneYaooo/rea-video).

## Overview
Shot2Key turns any reference video into a scene-by-scene storyboard (each scene capped at <= 10 seconds), generates structured prompts, and creates keyframe images via local AI CLIs (`agy` / `codex`) or AI provider APIs.
